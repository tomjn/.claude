# Dependencies

## Hallucinated reference prevention

- Verify before referencing. For any URL, package, CLI tool, or API endpoint not already in the codebase, confirm it exists before writing it.
- Confirm the exact name, version, and import path. A name that "sounds right" is the number one source of hallucinated references.
- Ask me if you do not know the real URL.

## Dependency hygiene

- Ask before suggesting any new dependency.
- Respect lock file constraints.
